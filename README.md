
# 👩🏻‍💻 QR Code Generator

A simple and stylish QR Code Generator built using HTML, CSS, and JavaScript. Generate QR codes instantly by entering any text or URL.

## 🌐 Live Demo

🔗 [View Live Project](https://qr-code-generater-three.vercel.app/)

## 📸 Project Screenshot

(![QR Code Generator Preview](./Picture.png))

## ✨ Features

- Generate QR codes from text.
- Generate QR codes from URLs.
- Fast QR code generation.
- Clean and attractive pink-themed UI.
- Simple and user-friendly interface.
- Uses QRServer API.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- QRServer API

## 💡 How to Use

1. Enter any text or URL.
2. Click the Generate QR Code button.
3. Wait for the QR code to generate.
4. Your QR code will appear on the screen.

## 🌐 API Used

[QRServer API](https://goqr.me/api/)
